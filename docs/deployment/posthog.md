# PostHog Setup

## Create Project

1. Sign up at [posthog.com](https://posthog.com)
2. Create project: `voeq-production`
3. Region: US
4. Copy Project API Key

## Environment Variables

- `NEXT_PUBLIC_POSTHOG_KEY`
- `NEXT_PUBLIC_POSTHOG_HOST` (default: `https://us.i.posthog.com`)

## Free Tier

- 1M events/month
- 5k recordings/month
- Monitor in PostHog dashboard
